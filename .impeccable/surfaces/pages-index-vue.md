Scope: whole product, one shared world. Public site (every public route, navbar, footer) is mode Persuade; admin dashboard and login are mode Operate (world enters only through type, palette, density, one signature move). Presentation-layer only: scripts, stores, bindings, conditions, routes, props, emits, fields unchanged. Imagery: church's own uploads only; typographic/tone fallbacks when empty, no bundled stock. Homepage recomposed from existing data only; no new fields, no mock content.

Audience/task: first-time visitors and older congregants on phones (service times, watch, read, register, message); staff doing weekly record-keeping.

## Direction contract

THESIS: The church as a cultural institution in print: an editorial publication you walk through like a nave, cover first. Refuses the photo-banner + three icon cards church template and the grey SaaS dashboard.

OWN-WORLD: Warm ivory page (#FAF8F3) with stone alternates (#F3EFE6); charcoal night fields (#1A1916) for the cover, live worship and the close; deep forest (#2F3D2C) as the committed colour field (directory, primary actions, admin rail); champagne/bronze (#8A6A3B on ivory, #D4BC8E on night) only for hairline marks, dates, active indicators. Instrument Serif display (oversized, italic turns), Manrope text; small tracked uppercase labels as side-rail marginalia and metadata, never above a heading. Square corners (0–4px), warm stone hairlines, almost no shadow.

STORY: Visitor sees this church's own photograph and name as a magazine cover, reads the minister's letter, watches live or recent services, browses teachings and events as editorial lists, finds a congregation, and writes or registers. Staff work in the same type and palette with standard controls.

FIRST VIEWPORT: Full-bleed church photograph at 100svh under a charcoal veil; transparent navbar in ivory over it; church name set huge (up to 6rem) bottom-left in Instrument Serif with the settings eyebrow as an italic first line; address and tagline in a narrow column; existing primary CTA as a solid ivory button, secondary as hairline ghost; thin animated scroll line bottom-right. Headline lines rise from masks; photo settles from 1.08 scale.

FORM: seed: none (pinned) — "Modern editorial website aesthetics... Warm ivory / off-white for primary backgrounds. Deep charcoal or near-black for strong visual contrast. Muted olive, forest green... Subtle champagne, muted gold, or warm bronze... An elegant editorial serif font for prominent headings. A clean, modern sans-serif... The hero should feel like an editorial cover, not a conventional website banner." Signature interaction: clip-path image unveils and masked line reveals on scroll, one orchestrated grammar; navbar transparent-to-solid with a sliding bronze active hairline.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
